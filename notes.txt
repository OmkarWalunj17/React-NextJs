What are the two options to setup a React Project ?

1) Create React App
2) Vite  

=========================================================================================

Create React App :
1) Already configured with ESLint, Prettier, Jest and Babel.
2) Uses slow and outdated technologies under the hood like webpack.
3) Never use for a real world app, must be used only for tutorials and experiments.

=========================================================================================

Vite :
1) Modern build tool 
2) Also contains starter templates
3) Manual setup of ESlint, Prettier and Jest.
4) Used for modern world apps.
5) Extremely Fast Hot Module Replacement (HMR).

=========================================================================================

Creating a New React App :
1) using CRA : npx create-react-app@5 pizza-app

Output : 
Success! Created pizza-app at D:\React-NextJs\02-Using-CRA-For-Project-Creation\pizza-app
Inside that directory, you can run several commands:

  npm start
    Starts the development server.

  npm run build
    Bundles the app into static files for production.

  npm test
    Starts the test runner.

  npm run eject
    Removes this tool and copies build dependencies, configuration files
    and scripts into the app directory. If you do this, you can’t go back!

We suggest that you begin by typing:

  cd pizza-app
  npm start

Happy hacking!

--------------------------------
npm run build 

The project was built assuming it is hosted at /.
You can control this with the homepage field in your package.json.

The build folder is ready to be deployed.
You may serve it with a static server:

  npm install -g serve
  serve -s build

-------------------------------------------------------------------------------------------

2) using vite : npm create vite@latest

This will show you a list of templates to choose from.

Alternate way :

npm create vite@latest my-react-app -- --template react

npm create vite@latest my-react-app -- --template react-ts

React.StrictMode:
The only thing it does is that during development it will render all components twice in order to find certain bugs.

And also React will check if we're using outdated parts of the React API.

===============================================================================================

Components : 
1) React applications are entirely made out of components.
2) Building blocks of user interfaces in React. 
3) React takes all components and draws them on a webpage/UI.
4) Technically, React renders a view for each component.
5) And all these views together make up the UI.
6) Component can also be called a piece of UI that has its own data, JS logic, 
   and appearance how it works and looks).
7) We build complex UIs by building multiple components and combining them.
8) Components can be reused, nested inside each other, and pass data between them.
